# Path of Building: PoE2 — Agent Notes

## What this is
- An offline build planner for *Path of Exile 2*: passive tree, skills, items, and offence/defence calculations.
- This repo contains the full LuaJIT source (`src/`), the custom runtime/graphics host (`runtime/`), exporter tooling (`src/Export/`) for game data, and Busted specs (`spec/System/`).

## Tech stack
- LuaJIT 5.1 application with a custom C graphics host (`runtime/`). Source lives in `src/`.
- Tests use [Busted](https://lunarmodules.github.io/busted/) and run headless via `src/HeadlessWrapper.lua`.
- Generated data files live in `src/Data/` and are produced by exporter scripts in `src/Export/Scripts/` from PoE GGPK data.

## Dev environment
- Launch the app from the repo to enable Dev Mode automatically:
  - Windows: `./runtime/Path of Building-PoE2.exe`
  - Linux: `wine ./runtime/Path of Building-PoE2.exe`
- Dev Mode disables auto-updates and sets the user path to the script path.
- To force Dev Mode OFF, comment out `src/Launch.lua:58-62` and provide a valid `manifest.xml` in `./src`.
- Mod cache is rebuilt automatically in Dev Mode. To force it, hold `Ctrl` while launching or set `REGENERATE_MOD_CACHE=1` with `luajit src/HeadlessWrapper.lua`.

## Tests
- Run all tests with Docker: `docker-compose up`
- Run a single spec file (requires a matching environment):
  ```
  busted --lua=luajit "spec/System/TestSkills_spec.lua"
  ```
- Config is in `.busted`: tests run from `src/`, use `HeadlessWrapper.lua` as the helper, and exclude specs tagged `builds`.
- CI uses container `ghcr.io/pathofbuildingcommunity/pathofbuilding-tests:latest` and shards specs across 3 jobs (`spec/System/*_spec.lua`).

## Regenerating generated data
- `src/Data/ModCache.lua` is generated from `src/Modules/ModParser.lua`.
- Other files under `src/Data/` are generated by scripts under `src/Export/Scripts/` using the dat viewer at `src/Export/Launch.lua`.
- Generated files have a header like `-- This file is automatically generated, do not edit!`. Edit the generator, not the output.
- After changing mod parsing, reload with `Ctrl+F5` and commit the resulting `src/Data/ModCache.lua` if it differs.

## Manifest & releases
- `manifest.xml` lists files with SHA-1 hashes for the updater. Generate/update it with:
  ```
  python3 update_manifest.py --in-place
  ```
- New files must be added to `manifest.cfg` before `update_manifest.py` will include them.
- PRs target the `dev` branch. `master` and `beta` are release branches.

## Code entry points
- GUI entry: `src/Launch.lua` → `src/Modules/Main.lua`.
- Headless entry / test helper: `src/HeadlessWrapper.lua`.
- Exporter/dat viewer entry: `src/Export/Launch.lua`.

## Lua / tooling quirks
- The repo is large; exclude `src/Data/**/*.lua`, `src/TreeData/**/*.lua`, and `src/Modules/ModParser.lua` from EmmyLua language-server scans to avoid crashes.
- `ConPrintf()` writes to the in-app console in Dev Mode. Search for `"==="` to find default debug prints.
- Holding `Alt` in Dev Mode adds internal mod/tooltip debug info.
